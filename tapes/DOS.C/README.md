# DOS.C floppy disks

This directory contains DOS.C floppy disk images in ImageDisk (`.IMD`) format.
The accompanying `.IMD.TXT` files contain image metadata.

`DP1100DisketteBoot.tap` is a cassette bootstrap used to boot the floppy disks
on a Datapoint 2200. The `.IMD` files are floppy disk images, despite this
directory being stored under `tapes`.
